# Design Tokens

This document provides a reference for all design tokens used in the Fantasion UI library. These tokens are defined in `styles/variables.scss` and should be used consistently across all components.

## Grid System

The design system uses a **4px grid system** for all spacing calculations. The `grid()` function multiplies by 4px:

- `grid(1)` = 4px
- `grid(2)` = 8px
- `grid(4)` = 16px
- `grid(6)` = 24px
- `grid(12)` = 48px

## Usage Guidelines

### Using Design Tokens

**In SCSS files:**
```scss
@use '@fantasion/ui/styles/variables' as *;

.my-component {
  padding: $spacer-md;
  background: $color-primary;
  border-radius: $border-radius;
  box-shadow: $shadow;
  transition: $transition-base;
}
```

**In React components:**
Design tokens are compiled into the CSS bundle. Use them via className or CSS modules.

### Best Practices

1. **Always use tokens instead of hard-coded values** - This ensures consistency and makes theme changes easier
2. **Respect the spacing scale** - Use the defined spacer tokens (xs, sm, md, lg, xl) rather than arbitrary pixel values
3. **Follow the grid system** - All spacing should be multiples of 4px using the `grid()` function
4. **Use semantic colors appropriately** - Choose colors based on meaning (success, danger, etc.) not appearance
5. **Maintain color contrast** - Ensure text is readable against backgrounds (WCAG AA minimum: 4.5:1 for normal text)
6. **Test responsive behavior** - Use the defined breakpoints for responsive layouts
7. **Apply consistent border radius** - Use the radius tokens to maintain visual consistency across components

## Accessibility Notes

- **Color contrast:** Primary purple (#472a7e) on white backgrounds meets WCAG AA standards (7.5:1 ratio)
- **Focus indicators:** Always provide visible focus states using `$color-primary` or `$color-input-focus-border`
- **Touch targets:** Ensure interactive elements are at least 44x44px (use `$spacer-lg` or larger for padding)
- **Text size:** Base font size of 16px is readable on all devices
